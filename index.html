Fix your eyes on the dot

Keep your gaze still. The page moves so the word being recited always passes under the dot.

Space play / pause · → next ayah · ← start of ayah / previous ayah · Shift+→ ← next / previous surah · < > slower / faster · PgDn PgUp turn page · + − zoom · click a word to start there

Loop: A / B set the loop start / end at the current ayah (press again to remove) · Shift+click a word sets A, Alt+click sets B · C clears the loop

Recite from memory: P starts listening from the ayah under the dot (or the A-B loop) · upcoming words stay hidden · H shows the next word · ← recite this ayah again · Space pause · Esc stop
